# HN Effective Dashboard

Проект сбора и обработки данных для построения Power BI дашборда.

## Источники данных

| Источник     | Папка                  | Описание                        |
|--------------|------------------------|---------------------------------|
| ОЭД          | data/raw/oed/          | Оперативно-экономические данные |
| ОКК          | data/raw/okk/          | Отдел контроля качества         |
| Обучение     | data/raw/learning/     | Данные по обучению              |
| KPI          | data/raw/kpi/          | Показатели KPI                  |
| USERS        | data/raw/users/        | Пользователи / сотрудники       |
| ENPS         | data/raw/enps/         | eNPS опросы                     |
| АТТЕСТАЦИИ   | data/raw/attestations/ | Аттестации сотрудников          |

## Структура проекта

```
config/          — настройки и маппинги
data/raw/        — исходные файлы по источникам
data/out/        — готовые витрины (parquet) для Power BI
scripts/         — парсеры и трансформации
tests/           — тесты
```

## Запуск

```powershell
# Активировать окружение
.\.venv\Scripts\Activate.ps1

# Запустить все парсеры
python scripts/run_all_parsers.py
```
